# 🎨 UI改善: 左パネルカテゴリボタンの色分け機能

## 📅 改善日時
2025年10月4日 19:15

## 🎯 改善の目的
左パネルの固有表現カテゴリボタンに、それぞれのカテゴリに対応する色を付けて視覚的な識別性を向上

## 🔍 改善前の状況
- すべてのカテゴリボタンが同じ色（Streamlitデフォルトの青/グレー）
- カテゴリの区別がテキストとアイコンのみ
- ハイライト表示の色とボタンの色に関連性がない

## ✅ 実装した改善内容

### 1. カテゴリ別色定義の追加
```python
# カテゴリ別の色定義（ボタン用）
button_colors = {
    'LAW_REFERENCE': {'bg': '#FFE4E6', 'border': '#FFB6C1', 'text': '#8B4B8B'},     # 薄いピンク
    'ARTICLE_REFERENCE': {'bg': '#E6F3FF', 'border': '#87CEEB', 'text': '#1E3A8A'}, # 薄い青
    'TIME_PERIOD': {'bg': '#E6FFE6', 'border': '#98FB98', 'text': '#2F5233'},        # 薄い緑
    'MONEY_AMOUNT': {'bg': '#FFFAE6', 'border': '#F0E68C', 'text': '#8B7355'},      # 薄い黄
    'ORGANIZATION': {'bg': '#F3E6FF', 'border': '#DDA0DD', 'text': '#663399'},      # 薄い紫
    'PROCEDURE': {'bg': '#FFE6F0', 'border': '#FFB6C1', 'text': '#8B5A7C'},        # 薄いピンク（別色調）
    'LEGAL_STATUS': {'bg': '#E6FFFF', 'border': '#AFEEEE', 'text': '#2F4F4F'},     # 薄いシアン
}
```

### 2. カスタムHTMLボタンの実装
```python
# 色付きボタンのHTMLスタイルを直接指定
button_bg = colors["border"] if is_selected else colors["bg"]
button_text_color = "#FFFFFF" if is_selected else colors["text"]
button_border = colors["border"]

custom_button_html = f"""
<div style="
    background: {button_bg};
    border: 1px solid {button_border};
    color: {button_text_color};
    padding: 0.3rem 0.5rem;
    border-radius: 4px;
    text-align: center;
    font-weight: {'bold' if is_selected else 'normal'};
    transition: all 0.2s ease;
    box-shadow: 0 1px 2px rgba(0,0,0,0.1);
">
    {button_text}
</div>
"""
```

### 3. 選択状態による色の変化
- **未選択時**: 薄い背景色（`bg`）+ カテゴリ固有のテキスト色
- **選択時**: 濃い背景色（`border`）+ 白文字で強調表示
- **ホバー時**: 透明度とスケール変化によるインタラクション効果

### 4. カラーバッジとの統一
```python
# カラーバッジもボタンと同じ色で統一
badge_html = (
    f'<div style="background-color: {colors["bg"]}; '
    f'border: 1px solid {colors["border"]}; '
    f'color: {colors["text"]}; ...">'
    f'<small>({category})</small></div>'
)
```
