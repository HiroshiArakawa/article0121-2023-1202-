## 問題の発見と診断

### 🔍 報告された問題
ユーザーが以下のような状態を報告：
```
２ 特許出願、請求その他特許に関する手続（以下単に「手続」という。）についての期間の末日が行政機関の休日に関する法律（<span style="background-color: #FFB6C1; padding: 1px 3px; margin: 0 1px; border-radius: 3px; font-weight: 500; border: 1px solid #FFB6C188; border: 2px solid #FF6B6B; box-shadow: 0 0 10px rgba(255, 107, 107, 0.5);" title="法律参照: 昭和六十三年法律第九十一号">昭和六十三年法律第九十一号）第一条第一項各号に掲げる日に当たるときは、その日の翌日をもつてその期間の末日とする。
```

**問題**: `<span`タグが`>`で閉じられておらず、`</span>`終了タグも見当たらない

#### 1. 詳細なデバッグスクリプトの作成

#### 2. 原因の特定
**重要な発見**: 
- 単体テストではspanタグは正常に生成されていた
- 問題は`app_with_ner.py`の`highlight_entities`関数内の**f-stringの複数行連結**にあった

```python
# 問題のあったコード
highlighted_part = (
    f'<span style="background-color: {color}; '
    f'padding: 1px 3px; margin: 0 1px; border-radius: 3px; '
    f'font-weight: 500; border: 1px solid {color}88; {border_style}" '
    f'title="{category_jp}: {entity_text}">'
    f'{entity_text}</span>'
)
```
